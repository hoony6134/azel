# Azel TV (Roku 대시보드)

Roku TV에 인프라·작업·GISTRA·일정을 카드로 띄우는 **보기 전용** 채널이에요. 디자인은 `assistant/design/roku/SPEC.md`
(차분한 편집 디자인)예요. 게이트웨이의 `GET /v1/tv?v=2`(PROTOCOL.md 3장)를 60초마다 읽고(끊기면 30초마다), 게이트웨이가
v=2를 모르면 `/v1/tv`(v1)로 저절로 내려가요. 승인 버튼도, 명령도 없어요.

- **화면**: 머리글(살아 있는 로고, "Azel", 날짜와 시계), 구분선으로 나뉜 요약 4칸(경고, 진행 중 작업, 다음 마감, 다음 통화),
  그 아래 섹션이 세로로 쌓여요: 지금 확인할 것(있을 때만) → 오늘 → 인프라 → Azel 작업 → 과제와 할 일. 카드 너비는
  내용을 따라요(긴급·마감 414, 시간표·작업 560, 노드 268)
- **리모컨**: ↑↓ 섹션(끝에서 처음으로 돌아가요), ←→ 카드, OK 옆 상세 패널(다시 OK나 뒤로 가기로 닫기), ▶‖ 화면 보호기,
  ⟲ 지금 새로고침, ✱ 설정, 뒤로 가기는 맨 앞 카드로(거기서 한 번 더 누르면 나가요)
- **상세 화면**: 인프라 카드에서 OK를 누르면 서버마다 상태(CPU·메모리·디스크·온도·켜진 시간)와 서비스마다 종류·상태·24시간
  가동률·응답 시간·마지막 장애가 나와요(`GET /v1/tv?detail=infra`, Cygnus 상태 페이지와 같은 내용). Azel 작업 카드에서 OK를
  누르면 지금 하는 일(기기·엔진·시작 시각·지금 단계)과 최근 끝난 작업 10개의 결과 한 줄이 나와요(`?detail=tasks`).
  ↑↓ 이동, ⟲ 새로고침, 뒤로 가기로 닫아요
- **색**: 빨강은 지금 고장난 것, 호박색은 곧 챙길 것(마감 24시간 안, 승인, 주의 경고, 임계값 넘은 수치). 카드에는 테두리와
  색 배경이 없고, 색은 글자에만 써요
- **채널 아이콘·스플래시**: 앱 아이콘 그림(`design/icon/AppIcon-1024.png`)에서 Roku 크기로 만들어요(`tools/make_images.py`)
- **로고**: 도자기 오브가 천천히 숨 쉬고(±2.5%), 흔들리고(±1.5°), 가끔 빛이 스쳐요. 통화 중에는 두 배 빠르고 테두리가
  비서의 색으로 바뀌어요. 오류 화면에서는 회색으로 가만히 있어요
- **화면 보호기**: ▶‖ 또는 5분 동안 키를 안 누르면. 1분마다 6곳 중 다음 자리로 옮겨요. 아무 키나 누르면 돌아오고 그 키는
  다른 일을 하지 않아요
- **상태**: 처음 불러오는 중, 오류(다시 시도/설정), 토큰 오류(401), 연결 끊김(10분 넘으면 흐려져요), 일부만 실패한 섹션,
  빈 섹션
- **글꼴**: Pretendard Regular와 SemiBold(SIL OFL)를 KS X 1001 한글 2,350자와 영문·기호만 남겨 각각 약 0.3MB로 줄여
  넣었어요. 라이선스는 `fonts/OFL.txt`. 글자 크기는 24/30/34/44/56/200 여섯 가지뿐이에요
- **이미지**: `tools/make_images.py`가 카드·포커스 링(4px 안쪽 링) 9패치, 구분선, 도자기 오브(몸통, 테두리 유약, 빛)를
  만들어요(앱 아이콘과 같은 항아리 윤곽)
- **미리보기**: 서버 주소를 `demo`(통화 중이면 `demo-call`)로 하면 가짜 데이터로 화면을 볼 수 있어요(설정 화면이나
  `provision.sh`의 두 번째 인자)

화면은 **1920×1080**(`ui_resolutions=fhd`)으로 직접 그려요. 입문용 Roku Streamer HD처럼 가벼운 기기를 생각해서 이미지는 몇
장만 쓰고, 움직임은 로고와 RowList의 스크롤뿐이에요. 720p 기기에서는 Roku가 줄여 보여줘요.

## 1. 게이트웨이 쪽 준비

1. TV 전용 토큰은 `~/.config/biseo/tv_token`(0600, 32자 이상)에 있어요. 이 토큰은 `GET /v1/tv`만 열어요.
   바꾸려면 파일을 새 값으로 바꾸거나 지우세요(바로 폐기돼요, 재시작 필요 없음).
2. 기본 주소는 `https://azel.scian.xyz`예요(공개 주소 + TV 토큰). 프록시 허용 목록에 정확히 `GET /v1/tv`가 있어야 해요(배포 때
   DevOps가 추가). TV 토큰은 그 경로 말고는 모두 401이고, 게이트웨이 마스터 토큰도 그 경로에서 계속 돼요.
   Tailscale 안이라면 `http://100.64.x.x:8892`처럼 게이트웨이 주소를 직접 써도 돼요(Roku는 Tailscale에
   못 들어가니, 그 경우 프록시가 필요해요).

## 2. 개발자 모드 켜기와 IP 주소 (한 번만)

**IP 주소 찾기**: Roku 홈 → **설정 → 네트워크 → 정보**에서 "IP 주소"를 봐요(예: `192.168.0.23`). 공유기 관리
화면의 연결 기기 목록(기기 이름 "Roku Streamer HD")에서도 볼 수 있어요. TV와 이 Mac은 **같은 Wi-Fi/공유기**에
있어야 해요. 공유기에서 이 기기의 IP를 고정해 두면 다시 찾을 일이 없어요.

**TV나 Roku의 지역 설정은 사이드로드와 상관없어요**(미국에서 산 기기여도 그대로 돼요).

**개발자 모드**(Roku Streamer HD도 같은 방법이에요; 기기마다 잘 안 되면 리모컨 배터리와 TV 입력이 Roku인지 보세요):

1. Roku 리모컨으로 **홈 ×3, 위 ×2, 오른쪽, 왼쪽, 오른쪽, 왼쪽, 오른쪽**을 차례로 눌러요.
2. 개발자 설정 화면에서 **Enable installer and restart**를 고르고, 약관에 동의한 뒤 **웹 서버 비밀번호**를
   정해요. 화면에 나오는 **TV의 IP 주소**를 적어 두세요.
3. 사용자 이름은 `rokudev`예요.

## 3. 묶어서 올리기

`roku/` 폴더 **안의 내용**을 zip으로 묶어요(폴더 자체가 아니라 `manifest`가 zip 맨 위에 있어야 해요).

```bash
cd assistant/roku && zip -r ../azel-tv.zip manifest source components fonts
```

브라우저에서 `http://<TV IP>`를 열고(사용자 `rokudev`, 위에서 정한 비밀번호) **Upload → 파일 선택
(`azel-tv.zip`) → Install**을 누르면 바로 실행돼요. 홈 화면 맨 끝에 "Azel TV"로 남아요(재부팅해도 유지).

## 4. 처음 실행: 주소와 토큰 넣기

토큰이 없으면 설정 화면이 먼저 떠요.

- **리모컨으로**: 위/아래로 "서버 주소", "토큰"을 골라 확인(OK) → 화면 키보드로 입력(Roku 모바일 앱의
  키보드로 붙여 넣으면 편해요) → "저장하고 시작".
- **한 번에 보내기(권장)**: 이 Mac에서 아래를 실행하면 토큰을 화면에 찍지 않고 TV로 보내요(같은 집 네트워크
  안에서만 가요).

  ```bash
  assistant/roku/provision.sh <TV IP> https://azel.scian.xyz
  ```

  `200`이 나오고 TV에서 대시보드가 뜨면 끝이에요. (Roku가 이 방식의 시작 인자를 안 받으면 리모컨으로 넣으세요.)

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "토큰이 맞지 않아요" | 토큰 값(앞 4자 확인), 파일이 0600인지, 게이트웨이가 같은 `~/.config/biseo`를 보는지 |
| "응답이 없어요" / "서버 오류" | 주소, 프록시가 `/v1/tv`를 통과시키는지, 게이트웨이 전체 모드인지 |
| 한글이 네모로 나와요 | `fonts/PretendardKR-Regular.otf`가 zip에 들어갔는지(`zip` 명령에 `fonts` 포함) |
| 키보드 창의 글자가 깨져요 | 시스템 글꼴이라 그래요. 창 제목은 영어로만 썼어요 |
| 일부 칸이 "(불러올 수 없어요)" | 그 항목의 원본(Cygnus, 캘린더 등)이 끊긴 거예요. 나머지는 계속 보여요 |

## 확인 못 한 것

Roku 기기에서 실행해 보지 못했어요(BrightScript 문법 검사기도 돌리지 못했어요). 처음 올릴 때 개발자 모드
화면의 디버그 콘솔(`telnet <TV IP> 8085`)로 오류를 보세요. 아이콘 이미지는 넣지 않았어요(사이드로드는
없어도 돼요). 스토어 배포용이 아니에요.
