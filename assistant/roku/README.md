# Azel TV (Roku 대시보드)

Roku TV에 인프라·작업·할 일·일정을 띄우는 **보기 전용** 채널이에요. 게이트웨이의 `GET /v1/tv`(PROTOCOL.md 3장)를
30~60초(기본 45초)마다 읽어요. 승인 버튼도, 명령도 없어요.

- 왼쪽/오른쪽: 인프라 → 작업 → 할 일·일정 페이지 넘기기
- 확인(OK): 화면 보호기 모드(큰 시계와 한 줄 요약, 1분마다 자리를 옮겨 번인을 막아요). 아무 키나 누르면 돌아와요
- 5분 동안 키를 안 누르면 저절로 화면 보호기 모드로 들어가요
- `*`(옵션) 키: 설정 화면(서버 주소, 토큰)
- 글꼴: Pretendard(한글 포함, SIL OFL)를 부분 추출해 넣었어요. 라이선스는 `fonts/OFL.txt`

## 1. 게이트웨이 쪽 준비

1. TV 전용 토큰은 `~/.config/biseo/tv_token`(0600, 32자 이상)에 있어요. 이 토큰은 `GET /v1/tv`만 열어요.
   바꾸려면 파일을 새 값으로 바꾸거나 지우세요(바로 폐기돼요, 재시작 필요 없음).
2. 기본 주소는 `https://azel.scian.xyz`예요. 프록시가 `GET /v1/tv`를 통과시켜야 해요(지금은 목록에 없어요).
   Tailscale 안이라면 `http://100.64.x.x:8892`처럼 게이트웨이 주소를 직접 써도 돼요(Roku는 Tailscale에
   못 들어가니, 그 경우 프록시가 필요해요).

## 2. 개발자 모드 켜기 (한 번만)

1. Roku 리모컨으로 **홈 ×3, 위 ×2, 오른쪽, 왼쪽, 오른쪽, 왼쪽, 오른쪽**을 차례로 눌러요.
2. 개발자 설정 화면에서 **Enable installer and restart**를 고르고, 약관에 동의한 뒤 **웹 서버 비밀번호**를
   정해요. 화면에 나오는 **TV의 IP 주소**를 적어 두세요.
3. 사용자 이름은 `rokudev`예요.

## 3. 묶어서 올리기

`roku/` 폴더 **안의 내용**을 zip으로 묶어요(폴더 자체가 아니라 `manifest`가 zip 맨 위에 있어야 해요).

```bash
cd assistant/roku && zip -r ../azel-tv.zip manifest source components fonts
```

브라우저에서 `http://<TV IP>`를 열고(사용자 `rokudev`, 위에서 정한 비밀번호) **Upload → 파일 선택
(`azel-tv.zip`) → Install**을 누르면 바로 실행돼요. 홈 화면 맨 끝에 "Azel TV"로 남아요(재부팅해도 유지).

## 4. 처음 실행: 주소와 토큰 넣기

토큰이 없으면 설정 화면이 먼저 떠요.

- **리모컨으로**: 위/아래로 "서버 주소", "토큰"을 골라 확인(OK) → 화면 키보드로 입력(Roku 모바일 앱의
  키보드로 붙여 넣으면 편해요) → "저장하고 시작".
- **한 번에 보내기(권장)**: 이 Mac에서 아래를 실행하면 토큰을 화면에 찍지 않고 TV로 보내요(같은 집 네트워크
  안에서만 가요).

  ```bash
  assistant/roku/provision.sh <TV IP> https://azel.scian.xyz
  ```

  `200`이 나오고 TV에서 대시보드가 뜨면 끝이에요. (Roku가 이 방식의 시작 인자를 안 받으면 리모컨으로 넣으세요.)

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "토큰이 맞지 않아요" | 토큰 값(앞 4자 확인), 파일이 0600인지, 게이트웨이가 같은 `~/.config/biseo`를 보는지 |
| "응답이 없어요" / "서버 오류" | 주소, 프록시가 `/v1/tv`를 통과시키는지, 게이트웨이 전체 모드인지 |
| 한글이 네모로 나와요 | `fonts/PretendardKR-Regular.otf`가 zip에 들어갔는지(`zip` 명령에 `fonts` 포함) |
| 키보드 창의 글자가 깨져요 | 시스템 글꼴이라 그래요. 창 제목은 영어로만 썼어요 |
| 일부 칸이 "(불러올 수 없어요)" | 그 항목의 원본(Cygnus, 캘린더 등)이 끊긴 거예요. 나머지는 계속 보여요 |

## 확인 못 한 것

Roku 기기에서 실행해 보지 못했어요(BrightScript 문법 검사기도 돌리지 못했어요). 처음 올릴 때 개발자 모드
화면의 디버그 콘솔(`telnet <TV IP> 8085`)로 오류를 보세요. 아이콘 이미지는 넣지 않았어요(사이드로드는
없어도 돼요). 스토어 배포용이 아니에요.
