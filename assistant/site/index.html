부르면 대답하는 비서

아젤은 전화를 걸 듯 말로 부르는 한국어 음성 비서예요. 일정 확인, 기상 전화, 집과 서버 컴퓨터의 명령 실행을 맡고 있어요.

개인 프로젝트개인용으로 만들어 혼자 쓰고 있고, 다른 사람에게는 제공하지 않아요.

부르는 방법

앱을 열지 않고 가까운 기기에서 바로 불러요.

  • “아젤” 하고 부르기이름만 듣도록 학습한 웨이크 워드가 Mac에서 기다려요.
  • 전화 한 통iPhone에서 진짜 통화처럼 울리고 받아요. CallKit을 써요.
  • 잠긴 iPhone의 Siri“아젤에게 전화해”는 잠금을 풀지 않아도 돼요.
  • Apple Watch손목에서 전화를 걸고 승인 요청도 처리해요.
  • Mac 패널단축키로 여는 눌러서 말하기 패널이에요.
  • CarPlay운전 중에 전화를 걸고 짧은 메뉴를 써요.

짧은 질문은 GPU 서버의 로컬 모델이, 복잡한 요청은 Claude가 처리해요. 앱에는 어느 쪽이 답했는지 표시돼요.

보안

승인
명령 승인은 앱에서 직접 탭해야 해요. 모델이나 토큰으로는 승인할 수 없어요.
위험도 분류
명령은 규칙, 로컬 모델, Claude Haiku 순서로 위험도를 판단하고, 판단이 서지 않으면 승인을 요청해요.
sudo
자동 승인이 켜져 있어도 sudo, 재부팅, 디스크 삭제, git push는 매번 승인을 받아요. sudo는 강조된 승인 화면에서 승인한 한 번만 실행돼요.
개인 배포
공개 서비스가 아니에요. 토큰은 사용자 기기에만 저장되고, 음성 서버는 해시만 보관해요.
